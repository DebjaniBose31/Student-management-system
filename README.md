# Student Management System

This project is a Laravel CRUD application used to manage student records.

## Features
- Add Student
- View Student List
- Edit Student
- Delete Student

## Technologies Used
- Laravel
- PHP
- MySQL
- HTML
- CSS

## Description
This project demonstrates CRUD operations using Laravel MVC architecture. Users can add, view, update, and delete student information stored in a MySQL database.
